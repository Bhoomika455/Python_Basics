# Python_Basics
Python Introduction 🐍

Welcome to my Python Introduction notebook!

This notebook contains hands-on practice with Python basics. It introduces core concepts through short code examples and simple experiments for anyone beginning to learn Python.

## 📚 Topics Covered

### 1. Introduction to Python

- What Python is and where it can be used
- Basic Python expressions and arithmetic
- Comments in Python
  - Single-line comments
  - Multi-line comments

### 2. Identifiers and Naming Rules

Learn how to name variables and identifiers in Python:

- Names should not begin with a number
- Names should not contain spaces or special characters
- Python keywords cannot be used as identifiers
- Names are case-sensitive
- Letters, numbers, and underscores can be used

### 3. Variables and Data Types

The notebook introduces variables and Python's basic built-in types:

- Strings (`str`)
- Integers (`int`)
- Floating-point numbers (`float`)
- Booleans (`bool`)
- Checking a value's type with `type()`

### 4. Type Casting

Practice converting values between common types with:

- `int()`
- `float()`
- `str()`
- `bool()`


### 5. Strings

Explore string values and common operations:

- Finding the length of a string with `len()`
- Accessing characters with positive and negative indexes
- Extracting parts of a string with slicing
- Using a slice step to select characters
- Changing letter case with `upper()` and `lower()`
- Checking prefixes and suffixes with `startswith()` and `endswith()`
- Searching with the `in` operator
- Replacing text with `replace()`
